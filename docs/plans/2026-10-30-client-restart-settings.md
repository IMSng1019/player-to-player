# 客户端重启与个人设置修复计划

**目标：** 修复测试中环境准备后反复重启却不能进入服务器的问题，并保留隔离客户端的个人设置。

**设计：** 继续使用独立游戏目录隔离服务器模组与配置。个人选项另存于各世界目录的 `client-settings/`，首次继承当前客户端，后续安装优先恢复该服务器的设置；正常退出及再次重启时保存当前设置。仅迁移明确的本机选项文件，不混入其他服务器的模组配置或登录凭据。个人选项不参与服务器环境发布与启动校验。

**技术栈：** Java 17、Fabric 1.20.4、JUnit 5、Gradle Wrapper。

## 执行步骤

1. 对照 `test_log/26.10.30` 与实际生成的隔离实例，记录下载、启动、回服的证据；核查启动参数、Fabric 模组来源和启动快照判定。
2. 为确定的重复重启根因补充失败测试，再修复对应边界；保留现有单连接链自动重启预算。
3. 新增 `ClientLocalSettings` 及文件系统测试，覆盖首次继承、重装保留、服务器隔离与原目录不被覆盖；在环境路径策略中排除个人选项。
4. 在 `ClientRuntimeProfile` 安装、`ClientEnvironmentRestart` 重启/停止生命周期中接入设置保存与恢复，并补充可定位失败条件的日志。
5. 运行定向回归、完整 `test build` 和正式 JAR / Java 17 重启进程冒烟；按可用环境验证客户端回服，不把无图形进程验证当作真实账号联机验收。
6. 独立审查修改，记录验证结果并提交本次修复；保留任务开始时已有的两份文档修改。
