# 两版实测问题修复实施记录

**目标：** 修复主副切换权限丢失、端口发现空等、切换等待心跳超时以及分离回并/旧区块请求阻塞停服。

**授权：** 用户已于 2026-10-22 要求实施前一轮诊断中的修复，允许多个 agent 协作。当前工作区干净，在当前工作区按文件分工修改，不自动提交或发布。

**架构：** 保留物理服权威权限、区块唯一写者和原版世界生命周期。权限快照与本地实例生命周期分离；连接准备按实际连接隔离；已提交迁移的旧实例在停服前退休请求；分离以真实加载边界和旧组停止写入为前提。不能把限时冷却当成边界交接，也不能把未授权加载当成空区块成功。

**技术：** Fabric 1.20.4、Java 17、JUnit 5、Gradle wrapper。

## 1. 权限应用

- 文件：`group/LocalPermissions.java`、`group/GroupServerHooks.java`、`client/group/GroupHost.java` 及对应测试。
- 先添加名单先到/玩家后到、实例重建保留名单、重连重新推送权限、撤权及跨组隔离回归。
- JOIN 直接处理回调玩家，使用明确 tick 阶段补核；宿主启动只清实例级应用记录；真正退出会话才清名单。
- 聚焦验证：`./gradlew.bat test --tests '*LocalPermissions*'`。

## 2. 端口发现

- 文件：`client/net/PortSyncClient.java`、`server/PortSyncServer.java`、`netproto/PortSyncPacket.java` 和纯状态机回归。
- 核实当前 Fabric 1.20.4 自定义包注册/收发 API，先复现同连接早包、JOIN 初始化、旧连接迟到问题。
- 正确注册协议，按连接保存早到有效端口；JOIN 不丢同连接数据；必要时补显式请求/响应，保留旧服务端回退。
- 聚焦验证：`./gradlew.bat test --tests '*PortSync*'`。

## 3. 世界退出与旧申请退休

- 文件：`client/group/WorldSwitcher.java`、`client/group/MergeClient.java`、`group/ChunkClaimClient.java`、`group/GroupRuntime.java`、相关加载/保存入口及测试。
- 按原版先断开游戏连接再清客户端并等待停服，切换标志必须先设置。
- 添加迁移提交后旧代次退休测试：拒绝新申请、未决 future 结束、重试取消、迟到授予不能复活旧写者；保留最终保存的正确归属。
- 提交前失败仍保持原组；提交后不得重新启用旧写者。
- 聚焦验证：`./gradlew.bat test --tests '*ChunkClaim*' --tests '*GroupRuntime*'`。

## 4. 分离边界与准备

- 文件：`group/SplitMonitor.java`、`server/MergeCoordinator.java`、`registry/ChunkRegistry.java`、`group/MergeTriggers.java`、`client/session/WorldSession.java` 及对应测试。
- 检查真实区块申请范围、保留成员需求和跨维度依赖；先添加视距外围残留造成立即回并的回归。
- 完整移交可安全划分的区块，冻结并完成旧写者交接；无法确认依赖可分割时继续原组，禁止强拆。
- 新旧组均识别本次过渡，防止基于旧响应回并；正常真实相遇仍允许合并。
- 验证：分离几何/边界/成员变化/失败恢复/迁移后旧申请测试。

## 5. 加载反馈与性能定位

- 加入和切换过程显示明确阶段，目标世界就绪前不误示可玩；不绕过原版兼容入口。
- 细分预同步主线程排队、采集、压缩、发送及接收耗时，避免仅用尾部 ACK 宣称切换时延。
- 环境扫描排除实际使用的 `.p2p-tmp` 临时文件，避免扫描短命文件失败。
- 控制台命令下放作为独立入口核查，复用既有权限与命令路由约束，禁止盲目广播管理命令。

## 6. 集成验证与复查

- 各 agent 只修改约定文件；Gradle 由主 agent 串行运行。
- 先观察新增回归失败，再实施并聚焦重跑；最终 `./gradlew.bat test build` 和 `git diff --check`。
- 独立复查代码及唯一写者、权限隔离、会话取消/迟到消息约束，修复发现后重跑相关测试。
- 多机验收：OP 主变副、在线 op/deop；两人合组后主/副分别远 TP；等待中取消；直连/中转；跨维度票据；一致版本下相同世界与角色方向 A/B 计时。
- 本地测试/构建不能替代真实多机 smoke test，交付时如实记录未验证项目。
